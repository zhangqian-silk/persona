它知道你在忙什么。

Persona 和你所有的 Agent 共用一份上下文。派活之前它先看一眼，Agent 就不用从零问起。

  • 知识库

    飞书和邮件里的人、群、项目，沉淀成你自己机器上的文件。Persona、AI 分身和 Agent 读的都是这一份。

  • 收件箱

    飞书、邮件、GitHub 汇进一个收件箱。AI 先分好拣，该回的替你起好草稿，你看一眼再发。

  • 手机里的数据

    通讯录、日历、提醒事项、照片、健康和位置都能当工具用；要往里写的，先在手机上等你确认。

你的每台电脑，连成一张网。

在一台常开的机器上跑 hub，其他电脑装上 Persona Link 就连进来了。笔记本断网后会自己重连，不用 SSH，也不用 VPN。

打开 TestFlight

自己搭一个

  1. 在一台常开的机器上装 hubLinux 或 Mac 都行，贴这一行。Mac 上要先装 Docker Desktop 或 OrbStack。
    $ curl -fsSL https://github.com/nwverse/persona/releases/latest/download/install.sh | sh -s -- --hub
  2. 手机扫码配对装完终端里会打出一个二维码，用 iPhone 相机扫一下就连上了。二维码 10 分钟内有效、只能用一次；过期了，在 hub 那台机器上运行 personad hub pair 再出一个，或者把上面这行再贴一遍。
  3. 连上你的电脑hub 那台机器先装了 Claude Code 的话，它自己就是第一台电脑；要加别的电脑，在网页版里点「添加电脑」，照屏幕上的提示做。
  4. 接上模型用你已经在用的 Claude Code，或者贴一个 API Key。

怎么打开

常见问题。

这里没有的，到 GitHub 提个 issue 问我们。

要开 VPN 或内网穿透吗？

不用。手机经公网直连你的 hub，连接是加密的，配对时也记住了 hub 的身份；在家里的局域网里照样能连。电脑那边由 Persona Link 主动连 hub，不需要公网地址。

支持哪些 Agent？

Claude Code、Codex、opencode、pi、DSH 和 Antigravity CLI。能做到哪些事，因运行时和它所在的终端引擎而异。想接别的 Agent，可以照着运行时规范自己接一个。

手机不在身边，Agent 卡住了怎么办？

要你处理的事会推到手机和手表，锁屏和灵动岛上能看到是哪台电脑的哪个 Agent，点开就能回答。技术细节类的问题，Persona 会先替你答，只有该你拍板的才来找你。

数据会经过你们的服务器吗？

只有推送会。没配自己推送密钥的 hub，经开发者运营的推送中继发通知：通知正文端到端加密，中继看不到；锁屏和灵动岛的实时活动按 iOS 要求是明文，经过中继时它看得到。介意的话，给 hub 配上自己的 APNs 密钥，或者自己搭一个中继。详见隐私政策。

怎么拿到 App？

iPhone 和 Apple Watch 版通过 TestFlight 公开测试，需要 iOS 26，装好可以先用体验模式。Android 安装包和 Mac、Linux、Windows 的组件可在下载与版本页从 GitHub 直接下载；网页版就在你的 hub 上，浏览器打开 hub 的地址就行。

换了手机、重装了 App，怎么重新配对？

在 hub 那台机器的终端里运行 personad hub pair，会打出新的二维码和配对链接，同样 10 分钟内有效、只能用一次；提示找不到这个命令的话，把安装命令再贴一遍，装好的部分不会重做，最后也会给你一个新码。还有别的手机或平板连着的话，不用回 hub 那台机器：在它的「设置 › 设备 › 连接新设备」里出码，用新手机扫。hub 重装了或者搬到了别的机器，用新 hub 打出的码，在 App 的「设置 › 重新配对」里扫；移除过的电脑，在网页版里重新「添加电脑」。其他情况见安装指南。

要花钱吗？

Persona 以 MIT 协议开源，自己部署就能用。模型走你自己的 Claude Code 订阅或 API Key。
