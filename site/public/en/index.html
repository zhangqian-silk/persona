It knows what you're working on.

Persona and all your Agents share the same context. It checks that context before handing out work, so your Agents don't have to start from scratch.

  • Knowledge base

    People, groups and projects from Lark and email become files on your own machine. Persona, your AI personas and Agents all read the same files.

  • Inbox

    Lark, email and GitHub flow into one Inbox. AI sorts everything first and drafts replies that need one, so you can review and send.

  • Phone data

    Contacts, calendar, reminders, photos, health and location can all be used as tools; anything that writes to them waits for your confirmation on the phone.

Every computer, connected.

Run the hub on an always-on machine, then install Persona Link on your other computers to connect them. A laptop reconnects automatically after going offline—no SSH or VPN required.

Your data stays
on your own machines.

Persona has no user accounts and does not collect or sell any data. You host the hub yourself. Content is sent to your chosen model provider only when you ask AI to work on it, as part of that conversation.

Stored with you
Conversations, your Inbox and settings live on the hub machine; your knowledge base is a set of files on your disk.
Encrypted secrets
Email passwords and model API keys are encrypted before storage, and the decryption key is kept out of the database.
Only your hub
Your phone remembers the hub's identity when pairing, so it can verify it's connected to that same hub over the public internet.
Push notifications
Notification content is end-to-end encrypted, so the relay cannot read it. Live Activities on the Lock Screen and Dynamic Island are in plain text as iOS requires; if that concerns you, configure your own push key on the hub.
Ask before writing
Actions that change something, such as editing your calendar or sending a message, wait for your approval on your phone.
Open code
Open source under the MIT license, so you can inspect how data is stored and transmitted on GitHub.

Set up your own

  1. Install the hub on an always-on machineLinux and Mac both work; paste this one line. On a Mac, install Docker Desktop or OrbStack first.
    $ curl -fsSL https://github.com/nwverse/persona/releases/latest/download/install.sh | sh -s -- --hub
  2. Pair your phone with a QR codeWhen installation finishes, the terminal shows a QR code. Scan it with your iPhone camera to connect. The code is valid for 10 minutes and can be used only once. If it expires, run personad hub pair on the hub machine for a new one, or paste the command above again.
  3. Connect your computersIf Claude Code is already installed on the hub machine, that machine becomes your first computer. To add others, click “Add computer” in the web app and follow the on-screen instructions.
  4. Connect a modelUse your existing Claude Code setup, or paste an API key.

Frequently asked questions.

If your question isn't covered here, open an issue on GitHub and ask us.

Do I need a VPN or network tunneling?

No. Your phone connects directly to your hub over the internet with an encrypted connection and remembers its identity from pairing. It also works on your home LAN. Persona Link initiates the connection from each computer to the hub, so your computers don't need public addresses.

Which Agents are supported?

Claude Code, Codex, opencode, pi, DSH and Antigravity CLI. Capabilities vary by runtime and engine. To connect another Agent, follow the runtime specification and build your own integration.

What if an Agent gets stuck while my phone isn't with me?

Anything that needs you is pushed to your phone and watch. The Lock Screen and Dynamic Island show which Agent on which computer is waiting, and you can open it to respond. Persona handles technical questions for you and only brings you decisions that are yours.

Does my data pass through your servers?

Only push notifications do. A hub without its own push key sends notifications through a relay operated by the developer. Notification content is end-to-end encrypted, so the relay cannot read it. Live Activities on the Lock Screen and Dynamic Island are in plain text as iOS requires, so the relay can see them. If that concerns you, configure your own APNs key on the hub or run your own relay. See the privacy policy for details.

How do I get the app?

The iPhone and Apple Watch versions are in public beta through TestFlight, require iOS 26, and offer demo mode after installation. Android installers and components for Mac, Linux and Windows are available directly from GitHub on the Downloads and releases page. The web app lives on your hub: just open your hub's address in a browser.

How do I pair again after changing phones or reinstalling the app?

Run personad hub pair in a terminal on the hub machine to print a new QR code and pairing link. Again, the code is valid for 10 minutes and can be used only once. If the command isn't found, paste the install command again: completed steps are skipped and you'll get a new code at the end. If another phone or tablet is still connected, you don't need to return to the hub machine: create a code there under Settings › Devices › Connect New Device and scan it with your new phone. If you reinstalled or moved the hub, scan the new hub's code under Settings › Pair Again in the app. For a removed computer, use “Add computer” in the web app again. For other cases, see the installation guide.

Does it cost anything?

Persona is open source under the MIT license and free to self-host. Models use your own Claude Code subscription or API key.
